## 1. ЛАКРА (lakra-products.ru)

### Профессиональные линейки

У «Лакры» **нет единой B2B-линейки для застройщиков**, но есть несколько отдельных брендов, ориентированных на профессиональных маляров и строителей:

#### 1.1. PROF it
- **Назначение:** краски для стен и потолков профессионального класса
- **Состав:** акриловая водно-дисперсионная основа, супербелая, латексная
- **Фасовки:** 3, 14, 25 кг
- **Особенности:** высокая укрывистость, матовое покрытие, без запаха
- **Источник:** https://lakra-products.ru/catalog/kraski-dlya-sten-i-potolkov

#### 1.2. Proremontt
- **Назначение:** отдельная торговая марка группы компаний «Лакра»
- **Ассортимент:** грунтовки (акриловые, алкидные), краски для стен и потолков, фасадные краски, эмали по дереву и металлу, деревозащитные средства
- **Фасовки:** 4, 14, 20 кг (профессиональные объёмы)
- **Источник:** https://lakra-products.ru/catalog/proremontt

#### 1.3. SUPER O'KRASKA
- **Назначение:** премиальная линейка Лакры
- **Особенности:** трещиностойкое резиновое покрытие, эластичность от −40°C до +50°C
- **Фасадная краска «Суперстойкая»** — прогнозируемый срок службы покрытия **более 15 лет**
- **Источник:** https://lakra-products.ru/catalog/super-okraska

#### 1.4. Лакра ДЕКОР
- **Назначение:** декоративные штукатурки и фактурные краски

### Вывод по Лакре
У компании есть несколько профессиональных линеек (PROF it, Proremontt, SUPER O'KRASKA, Лакра ДЕКОР), но **отсутствует специализированная программа для B2B-сегмента жилищного строительства** (нет комплексных системных решений «грунт + шпатлёвка + краска» под единым брендом для застройщиков).

## 2. АКЗО НОБЕЛЬ (an-powdercoatings.ru)

### Профессиональная B2B-линейка: ✅ ДА — Interpon D (архитектурная серия)

AkzoNobel специализируется на **порошковых покрытиях** — это не ЛКМ в традиционном смысле, а покрытия, наносимые на металлические изделия в заводских условиях. Линейка **Interpon D** — единственная специализированная архитектурная B2B-серия из трёх рассмотренных производителей.

### Структура архитектурной линейки Interpon D

| Серия | Применение | Стандарт |
|---|---|---|
| **Interpon D1000 / D1036** | Стандартная долговечность | Базовый уровень |
| **Interpon D2000 / D2525** | Повышенная долговечность | GSB / AAMA |
| **Interpon D3000 Fluoromax** | Ультра-долговечность (фторполимер) | Qualicoat Class 2 |

### Области применения в жилищном строительстве
- **Алюминиевые профили** для оконных и дверных систем в жилых зданиях
- **Архитектурный металлический профиль** (фасады, перила, фурнитура)
- **Металлокассеты** для вентилируемых фасадов жилых комплексов
- **Двери** в жилые подъезды
- **Перила и ограждения** балконов и лестничных клеток

### Сертификация
- Соответствие международным стандартам: **AAMA, GSB, Qualicoat**
- Не содержит растворителей — экологически безопасно
- Сайт архитектурной страницы: https://an-powdercoatings.ru/architecture

### Цитата с сайта
> «Архитектурные порошковые краски специально разработаны для применения в архитектурной и строительной отраслях. Краски используются для отделки жилых и коммерческих зданий по всему миру. Серия Int D включает порошковые покрытия премиум-класса, которые соответствуют основным международным архитектурным стандартам качества.»

### Вывод по Акзо Нобель
У AkzoNobel **есть чёткая B2B-линейка для жилищного строительства** — Interpon D. Однако это **узкоспециализированный сегмент**: порошковые покрытия наносятся только в заводских условиях на металлические изделия. В жилом строительстве они применяются **не напрямую застройщиками**, а через производителей алюминиевых профилей, окон, дверей и металлоконструкций.

## Рекомендации для Эмпилс

На основе анализа конкурентов:

1. **Capatect — главный ориентир.** Caparol показывает, что застройщикам нужны не отдельные краски, а **комплексные системные решения**. У Эмпилс уже есть 11 систем (Б1-П5, СП1-СП2) — это сильное преимущество, которое нужно активнее продвигать.

2. **PRO-серия для жилого строительства.** У конкурентов есть чёткое разделение «обычная краска» vs «профессиональная краска для строителей» (Indeko Plus Pro, Proremontt, PROF it). Эмпилс может усилить NEWTONE/AVANTGARDE как явную «PRO-линейку для B2B».

3. **Сертификация — единственное уникальное преимущество.** Ни Лакра, ни Caparol не имеют системной сертификации по ФЗ-123 для жилого строительства. Эмпилс может занять эту нишу: «единственная российская B2B-система с КМ1 на все ключевые SKU».

4. **Ценовое позиционирование.** Caparol — 16 380 ₽ за 10 л (премиум). Лакра PROF it — 1 327 ₽ за 3 кг (бюджет-средний). Эмпилс с ОРЕОЛ ДИСКОНТ/ОРЕОЛ/NEWTONE закрывает весь спектр — это преимущество, которого нет ни у одного конкурента.
