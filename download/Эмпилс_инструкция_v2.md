# Инструкция по настройке письма в UniSender

## Что внутри пакета

```
empils_email_template/
├── email.html        ← HTML-код письма (готов к вставке в UniSender)
├── logo_empils.jpg   ← Логотип (если понадобится загрузить вручную)
└── INSTRUCTION.md    ← Этот файл
```

---

## Шаг 1. Вставка HTML в UniSender

1. Откройте https://app.unisender.com/ru/
2. **«Сообщения» → «Email» → «Создать email»**
3. На экране выбора шаблона выберите **«HTML-код»** (или в блочном конструкторе переключитесь в режим HTML через кнопку `< >` / «Источник»)
4. Откройте файл `email.html` в любом текстовом редакторе (Блокнот, Notepad++, VS Code)
5. Выделите весь код (Ctrl+A) и скопируйте (Ctrl+C)
6. Вставьте в окно HTML-редактора UniSender (Ctrl+V)
7. Нажмите **«Сохранить» / «Применить»**
8. Перейдите в **«Предпросмотр»** — проверьте, как выглядит письмо

---

## Шаг 2. Загрузка логотипа (важно!)

В шаблоне логотип уже подставлен с официального сайта Эмпилс:
```
https://www.empils.ru/local/templates/empils/img/logo.png
```

**Если логотип не отображается** в предпросмотре UniSender — загрузите вручную:

1. В режиме HTML найдите строку (около 25-й строки):
   ```html
   <img src="https://www.empils.ru/local/templates/empils/img/logo.png" ...
   ```
2. В UniSender нажмите на изображение логотипа в предпросмотре
3. Выберите **«Загрузить изображение»** и укажите файл `logo_empils.jpg` (из этого пакета)
4. UniSender сам подставит новую ссылку на загруженное изображение

## Шаг 3. Настройка merge-полей UniSender

Шаблон уже содержит merge-поле для отписки:
```
{{UnsubscribeLink}}
```
Это стандартное поле UniSender — оно автоматически подставит ссылку отписки для каждого получателя.

**Если хотите персонализировать приветствие** — добавьте в начале письма (после заголовка) строку:
```html
<p style="margin:0 0 16px 0; font-size:15px; color:#5B6B7D;">
  Здравствуйте, {{Name}}!
</p>
```
Поле `{{Name}}` подставит имя получателя из вашей базы контактов.

## Шаг 4. Прикрепление презентации

В тексте письма есть упоминание: «📎 К письму прикреплена презентация». Чтобы прикрепить файл:

1. В редакторе письма найдите кнопку **«Прикрепить файл»** (обычно иконка скрепки 📎)
2. Загрузите PDF-презентацию «Эмпилс — компания и бренды»
3. Размер файла: желательно не более 5 МБ (иначе почтовые сервисы могут блокировать)
4. Если файл большой (>5 МБ) — загрузите презентацию на Яндекс.Диск / Google Drive и в письме дайте ссылку вместо вложения

**Альтернатива (лучше для доставляемости):**
В шаблоне уже есть блок «📎 К письму прикреплена презентация». Замените текст на:
```
📎 Скачать презентацию (PDF, 2 МБ)
```
И сделайте это текст ссылкой на файл в облаке.

## Шаг 5. Настройка статистики

### Базовая статистика (включается автоматически)
UniSender по умолчанию собирает:
- **Доставлено** — сколько писем дошло
- **Открытий** — сколько получателей открыли письмо
- **Кликов** — сколько кликнули по ссылкам
- **Отписок** — сколько отписались

### Расширенная статистика (UTM-метки)

Чтобы видеть переходы из письма в Google Analytics / Яндекс.Метрике:

1. **В ссылке на сайт** (в подвале письма) добавьте UTM-метки:
   ```
   https://www.empils.ru/?utm_source=unisender&utm_medium=email&utm_campaign=factory_visit_2026&utm_content=partner_invitation
   ```
   Где в HTML-коде найдите:
   ```html
   <a href="https://www.empils.ru" ...>www.empils.ru</a>
   ```
   И замените на:
   ```html
   <a href="https://www.empils.ru/?utm_source=unisender&utm_medium=email&utm_campaign=factory_visit_2026&utm_content=partner_invitation" ...>www.empils.ru</a>
   ```

2. **В ссылке на телефон** UTM не нужен — это не веб-ссылка.

### Настройка целей в UniSender

1. В меню UniSender выберите **«Аналитика» → «Цели»**
2. Создайте цель: **«Звонок региональному директору»**
   - Тип: переход по ссылке
   - URL: `tel:+79168058882`
3. Создайте цель: **«Переход на сайт»**
   - Тип: переход по ссылке
   - URL: `https://www.empils.ru`

### A/B-тестирование (опционально)

Если хотите протестировать 2 варианта темы письма:

1. В UniSender выберите **«Создать A/B-тест»**
2. Вариант A: «Откройте производство Эмпилс изнутри»
3. Вариант B: «Приглашение на завод Эмпилс — увидьте качество своими глазами»
4. Тест: 20% базы → через 4 часа победитель отправляется остальным 80%

## Шаг 6. Пребольшое письмо себе

**Перед отправкой всей базе** — обязательно отправьте тест:

1. Нажмите **«Отправить тест»** / **«Preview»**
2. Введите свой email
3. Проверьте на телефоне и на компьютере
4. Убедитесь, что:
   - ✅ Логотип отображается
   - ✅ Кнопка «Позвонить» кликабельна и набирает номер
   - ✅ Ссылка на сайт открывается
   - ✅ Текст читаем, ничего не обрезано
   - ✅ Презентация прикреплена или ссылка работает
   - ✅ Ссылка «отписаться» работает

## Шаг 7. Рекомендации по рассылке

- **Время отправки:** вторник-четверг, 10:00-12:00 по Москве
- **Тема письма:** «Приглашение на завод Эмпилс — увидьте качество своими глазами» (или A/B-тест)
- **Preheader** (текст в превью): уже вставлен в HTML — «Откройте производство Эмпилс изнутри и убедитесь в качестве, которое продаёт само себя»
- **База:** проверьте, что у каждого контакта заполнено поле `Name` (для персонализации)
- **Частота:** не более 1 письма в 2 недели одному контакту
