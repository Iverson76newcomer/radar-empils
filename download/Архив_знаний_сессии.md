- Шпатлёвка — НЕ финишный отделочный материал (покрывается краской).

## 1.4. Концепция УБК (Универсальный Безопасный Квадрат)

### Суть концепции:
Продукты Эмпилс немногочисленны, но **универсальны** и при этом **сертифицированы** для жилого строительства. Универсальность для прораба = экономия на издержках, отсутствие неликвидных остатков, меньше SKU на складе.

### Формула УБК:
```
УБК = Универсальность × Безопасность / Количество SKU
```

### МИН-комплект прораба (3 SKU вместо 8-10 у конкурентов):
1. NEWTONE или ОРЕОЛ моющаяся → стены, потолки, коридоры (КМ1)
2. Эмаль глянцевая ОРЕОЛ → дерево, металл, радиаторы (Г1, В1, Д1, Т1)
3. ОРЕОЛ фасадная → фасады (КМ1)

### Преимущества УБК:
- Меньше SKU → меньше остатков → меньше затраты
- Все сертифицированы по ФЗ-123 — нет риска приёмки
- 1 поставщик вместо 4-5

### Аналог TCO для WD-направления:
TITAN = TCO (совокупная стоимость владения) для грунт-эмалей.
УБК = та же философия для WD-красок.

### Конкурентные концепции (изучены):
- Dulux: Lifecycle Tool (стоимость за 10-30 лет) + Assurance Warranty (гарантия 15 лет)
- Tikkurila: Эко-сертификация (для ЛПУ/детских) + системы цветов
- Ceresit: System Solution (комплекс «грунт+краска+гидроизоляция»)
- Caparol: Технологичность + долговечность (20 лет)
- Лакра/Основит: Цена + доступность
